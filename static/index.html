Python coding platform

Build questions, write code, and check every testcase in one clean workspace.

This project has two sides: admins can upload programming questions with input/output testcases, and users can select a question, write Python code, run it, and instantly see which tests passed.

Admin Side

Login as admin, create questions, add starter code, and save multiple testcase inputs and expected outputs.

User Side

Browse available questions, read the problem statement, write Python, reset starter code, and run the judge.

Compiler

The backend runs Python submissions against each testcase with a timeout, then compares actual output with the expected output.
